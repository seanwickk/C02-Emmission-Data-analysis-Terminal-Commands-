### CO₂ Emissions Review (2020)

This review examines 2020 CO₂ emissions data for our non-profit focused on climate and energy. The goal is to better understand where we should direct community protection and climate support efforts.

#### Dataset Overview
The data sheet contains approximately:
- **2 string columns**
- **3 integer columns**
- **1 float column**

**Columns:**
| Column       | Description          |
|--------------|----------------------|
| Country      | Country name         |
| ISO Code     | Country ISO code     |
| Year         | Year of data         |
| Population   | Population count     |
| GDP          | Gross Domestic Product |
| CO₂          | CO₂ emissions        |

#### Data Quality Notes
The CSV is generally well-structured, with consistent data types across each column. However, it contains a significant number of missing values, particularly in the **ISO Code** field.  

This occurs because the dataset includes places that are not formally recognized as countries. As a result, no standard ISO code can be assigned to those entries.

#### Important Considerations
Before relying on this (or any) emissions dataset, it is important to conduct background verification on:
- How CO₂ emissions are measured and classified
- The methodology and potential incentives of the original data source

A key question that emerged during this review is whether the two countries that dominate a particular category in the global ecosystem also account for a disproportionately large share of total CO₂ emissions.
